# Dank420 (DANK) Token 🌿💨

Welcome to the **Dank420** (DANK) token project! This repository contains the Solidity smart contract code and supporting documentation for the Dank420 cryptocurrency. Inspired by the cannabis culture, Dank420 is a deflationary token deployed on Ethereum, designed to bring together enthusiasts with gamified staking, NFTs, and support for cannabis legalization efforts. 🌱🔥

---

## **Key Features** 🌿

- **Total Supply**: 4,200,000,000 DANK tokens.
- **Burn Mechanism**: 4.20 tokens burned per transaction, creating a deflationary supply. 🔥
- **ERC-20 Compliant**: Fully compatible with Ethereum wallets and exchanges. 💼
- **Community-Oriented**: Supports governance and staking mechanisms for token holders. 🤝
- **Cannabis-Themed NFTs**: Unique digital collectibles representing iconic strains, bongs, and more. 🎨🍁

## **Installation** 🌱

### Prerequisites

Ensure you have the following installed:
- [Node.js and npm](https://nodejs.org/)
- [Hardhat](https://hardhat.org/)
- [Solidity Compiler](https://docs.soliditylang.org/)

### Clone the Repository 🌿

```bash
git clone https://github.com/yourusername/dank420.git
cd dank420
```

### Install Dependencies 💻

```bash
npm install
```

---

## **Usage** 💨

### Compile the Contract 🔧

```bash
npx hardhat compile
```

### Deploy the Contract 🚀

1. Configure your Ethereum wallet private key in the `.env` file.
2. Deploy the contract:

```bash
npx hardhat run scripts/deploy.js --network <network_name>
```

### Test the Contract 🧪

Run the test suite to verify the contract functionality:

```bash
npx hardhat test
```
